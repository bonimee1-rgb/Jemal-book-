
# Bon Quran

A complete multilingual Quran learning application.

## Languages
- Arabic — Original Quran text
- Amharic — Quran translation
- English — Quran translation
- Afaan Oromoo — Quran translation

## Features
- Complete 114 Surahs and verified Ayahs
- Search Quran by Surah or Ayah
- Read translations side by side
- Tafsir and explanations
- Quran audio recitation
- Bookmarks and reading history
- Hifz memorization tracker
- Daily reading goals
- Offline reading support

## Content standards
All Quran text and translations must come from verified sources.
Preserve the original Arabic text without modification.
Include source attribution and licensing information.
